<objective>
Integrate `sentry_flutter` for crash reporting with NFC noise filtering and background failure capture.

Purpose: Silent kiosk failures currently vanish into local `debugPrint` logs that nobody reads. Sentry surfaces real crashes (native + Dart), suppresses benign NFC session noise, and enriches background failure events with outlet/device context so ops can identify unstable kiosks.

Output: `sentry_flutter` initialized in `main.dart`, `SentryService` helper with NFC filter + throttled background capture, heartbeat and background services wired to report final failures.
</objective>
