## Typography

All values inherit from existing `buildAppTheme()` in `lib/core/theme.dart`. Plus Jakarta Sans via `google_fonts`.

| Role | Size | Weight | Line Height | Usage in This Phase |
|------|------|--------|-------------|---------------------|
| Body | 14px | 400 (regular) | 1.5 | Subtitle text, error messages, checkbox label |
| Label | 15px | 700 (bold) | 1.4 | Button text ("Masuk", biometric CTA) |
| Heading | 24px | 700 (bold) | 1.2 | Login greeting "Halo, Akmal" |
| Caption | 13px | 400 (regular) | 1.4 | Error container text, helper text |

Weights used: 400 (regular) for body text and captions, 700 (bold) for headings and button labels. Two weights only.

Source: Existing `headlineSmall` and `elevatedButtonTheme` in theme.dart. Heading consolidated from w800 to w700 to match button weight and maintain a 2-weight constraint.

## Color

All colors use existing `AppColors` from `lib/core/theme.dart`. No new colors introduced.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` (AppColors.background) | Scaffold background, login screen surface |
| Secondary (30%) | `#F9FAFB` (AppColors.surface) | Input field fill, card backgrounds |
| Accent (10%) | `#DC2626` (AppColors.primary) | Primary CTA button, focused input border, fingerprint icon highlight |
| Destructive | `#DC2626` (AppColors.danger) | Error container border/text, failed biometric message |

Accent reserved for:
- "Masuk" primary CTA button background
- Biometric fingerprint icon fill (when biometric is available)
- Focused input field border
- "Remember me" switch thumb when enabled

Additional semantic colors used:
- `#6B7280` (AppColors.textSecondary) -- subtitle text, checkbox label secondary state
- `#9CA3AF` (AppColors.textMuted) -- placeholder/hint text
- `#E5E7EB` (AppColors.border) -- input field default border, divider
- `#FEE2E2` (AppColors.dangerLight) -- error container background at 10% opacity

---

## Focal Point

The primary visual anchor is the "Masuk" CTA button. It is the only element using accent color as a filled background, making it the strongest focal point on the login screen. All other elements (form fields, biometric button, checkbox) use neutral or outlined treatments to direct attention toward the primary CTA.

## Component Inventory

### New UI Elements for This Phase

#### 1. Biometric Prompt Button (login screen)
- **Location:** Below the password field, above the "Masuk" button
- **Appearance:** Full-width OutlinedButton with fingerprint icon (Icons.fingerprint) + text
- **States:**
  - **Available:** Red outlined button, `Icons.fingerprint` at 24px in AppColors.primary, label "Masuk dengan Sidik Jari"
  - **Loading:** CircularProgressIndicator (20x20, strokeWidth 2) replacing icon, button disabled
  - **Unavailable/hidden:** Not rendered (device has no biometric or user has not enabled "Remember me")
- **Touch target:** 48px minimum height (matches existing ElevatedButton padding of 16px vertical)
- **Border radius:** 12px (matches existing button theme)

#### 2. "Ingat Saya" Checkbox (login screen)
- **Location:** Between the password field and the biometric button
- **Appearance:** Row with Checkbox + Text label
- **Layout:** `Row(children: [Checkbox, SizedBox(width: 8), Expanded(Text)])`
- **Checkbox:** Uses theme Switch/Checkbox styling (AppColors.primary when checked)
- **Label:** "Ingat saya di perangkat ini" in bodyMedium (14px, w400, AppColors.textPrimary)
- **Only visible when:** Device has biometric hardware (AUTH-04)

#### 3. Settings Dialog Toggle (admin shell)
- **Location:** Gear icon (`Icons.settings_outlined`, `semanticLabel: 'Pengaturan'`) in admin shell AppBar actions, opens a SimpleDialog/AlertDialog
- **Dialog content:** Single SwitchListTile for "Login Biometrik"
- **Switch subtitle:** "Gunakan sidik jari atau wajah untuk masuk" in bodySmall (13px, AppColors.textSecondary)
- **Dialog shape:** RoundedRectangleBorder(borderRadius: 20) -- matches existing logout dialog
- **Dialog background:** Colors.white -- matches existing logout dialog

#### 4. Biometric Gate Screen (inline, not a separate route)
- **Approach:** NOT a separate screen. On cold start, if biometric is enabled and session exists, the existing login screen auto-triggers `BiometricService.authenticate()` immediately
- **During prompt:** The native Android BiometricPrompt dialog appears (OS-provided, not custom UI)
- **On success:** Navigate to dashboard (same as successful email/password login)
- **On failure/cancel:** Show the standard email/password form (already rendered underneath)
- **Loading indicator:** Show a centered Column with `Icons.fingerprint` (48px, AppColors.primary) + "Memverifikasi..." text while awaiting biometric result

### Modified UI Elements

#### 5. Login Screen Layout Update
- **Current flow:** Logo > Greeting > Subtitle > Form (email + password) > Error > CTA
- **New flow:** Logo > Greeting > Subtitle > Form (email + password) > "Ingat Saya" checkbox > Error > Biometric button (if available) > "Masuk" CTA
- **Biometric auto-trigger:** If returning user with biometric enabled, show fingerprint icon + "Memverifikasi..." immediately, then reveal form on cancel/failure

#### 6. Admin Shell AppBar Addition
- **Current:** Title + logout icon button
- **New:** Title + settings gear icon + logout icon button
- **Gear icon:** `Icons.settings_outlined`, 22px, Colors.white (matches existing icon theme), `semanticLabel: 'Pengaturan'`
- **Position:** To the left of the existing logout icon in AppBar actions list

## Interaction States

### Biometric Login Flow (Cold Start)

```
App opens
  |
  v
Check: Supabase session exists? + biometric_enabled flag?
  |
  +-- Both true --> Show fingerprint icon + "Memverifikasi..."
  |                   |
  |                   +-- BiometricPrompt (native OS dialog)
  |                   |     |
  |                   |     +-- Success --> Set role from SharedPreferences --> Dashboard
  |                   |     |
  |                   |     +-- Cancel/Fail --> Reveal email/password form
  |                   |
  +-- Either false --> Show standard email/password login form
```

### "Ingat Saya" Toggle Flow (Login Screen)

```
User checks "Ingat saya di perangkat ini"
  |
  v
Check: BiometricService.isAvailable()?
  |
  +-- true --> Flag stored, after successful login biometric is active for next visit
  |
  +-- false --> Show SnackBar: "Perangkat ini tidak mendukung login biometrik"
                Uncheck the checkbox automatically
```

### Settings Dialog Toggle Flow

```
User taps gear icon in AppBar
  |
  v
Show dialog with SwitchListTile "Login Biometrik"
  |
  +-- Toggle ON --> BiometricService.authenticate() confirmation prompt
  |     |
  |     +-- Success --> Save flag, close dialog, show SnackBar "Login biometrik diaktifkan"
  |     |
  |     +-- Fail --> Keep switch OFF, show SnackBar "Verifikasi gagal"
  |
  +-- Toggle OFF --> Clear flag, show SnackBar "Login biometrik dinonaktifkan"
```

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Touch targets | All interactive elements minimum 44px height (biometric button 48px via padding) |
| Biometric fallback | `biometricOnly: false` allows device PIN/pattern as fallback (AUTH-02) |
| Screen reader | Biometric button uses semantic label; fingerprint icon has `semanticLabel: 'Sidik jari'` |
| Settings icon | Gear icon uses `semanticLabel: 'Pengaturan'` for screen reader identification |
| No biometric hardware | Checkbox and biometric button hidden entirely (AUTH-04), standard login works |
| Error visibility | Error container uses red border + light red background + 13px text for readability |
