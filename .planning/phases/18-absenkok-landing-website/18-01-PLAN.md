**File 1: `astro.config.mjs`**
```javascript
import { defineConfig } from 'astro/config';
import tailwindcss from '@tailwindcss/vite';
import vercel from '@astrojs/vercel';
import sitemap from '@astrojs/sitemap';

export default defineConfig({
  site: 'https://absenkok.vercel.app',
  output: 'static',
  adapter: vercel(),
  integrations: [sitemap()],
  vite: {
    plugins: [tailwindcss()],
  },
});
```

Key points:
- `output: 'static'` — CRITICAL for zero JS, CDN-edge delivery
- Tailwind v4 via `vite.plugins` (NOT `integrations`) — this is NOT @astrojs/tailwind
- `site` URL needed by @astrojs/sitemap to generate absolute URLs
- `adapter: vercel()` — optional for static but adds Vercel-specific optimizations
