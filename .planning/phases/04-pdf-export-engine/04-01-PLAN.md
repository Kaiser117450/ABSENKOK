    `_computeStats` logic:
    - Group summaries by `employee?.id ?? 'unknown'`
    - Per employee: hadirCount = summaries where status==normal AND firstMasuk!=null
    - Per employee: sakitCount = summaries where status==sakit
    - Per employee: avgMasukStr = `_avgTimeOfDayStr` of firstMasuk values on hadir days
    - Per employee: avgPulangStr = `_avgTimeOfDayStr` of lastPulang values on hadir days where lastPulang!=null
    - Per employee: totalKerjaStr = format sum of workDuration on hadir days as "Xj Ym"
    - Per employee: name = `employee?.name ?? 'Tidak Diketahui'`
    - Sort employeeRows by name case-insensitively
    - Global: totalHadir = count of normal rows with firstMasuk!=null
    - Global: totalDays = distinct dateLabel count, totalEmployees = distinct employee id count
    - Global: attendanceRate = totalEmployees > 0 && totalDays > 0 ? (totalHadir / (totalDays * totalEmployees) * 100) : 0.0
    - Global: avgWorkHours = sum of workDuration across all normal rows with workDuration!=null, divided by totalHadir (guard /0)
    - Format avgWorkStr as "Xj Ym" (e.g. "8j 12m")
    - Global: totalSakit = count of sakit rows
    - Global: totalScan = sum of scanCount

    `_avgTimeOfDayStr` logic:
    - If times is empty → return '--:--'
    - Average `(dt.hour * 60 + dt.minute)` across all times
    - Convert back: `'${(avg ~/ 60).toString().padLeft(2, '0')}:${(avg % 60).toString().padLeft(2, '0')}'`

    `_chunkEmployeeRows(rows, 25)`:
    - Split list into chunks of pageSize

    `_buildSummaryPage`:
