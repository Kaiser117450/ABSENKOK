## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding between icon+label |
| sm | 8px | Compact element spacing, badge internal padding |
| md | 16px | Default element spacing, card horizontal margin, section inner padding |

| xl | 32px | Layout gaps between diagnostic sections |

- Touch targets: 48px minimum height for Force Sync button (Material 3 standard)

### Interaction Patterns

| Interaction | Behavior |
|-------------|----------|
| Force Sync tap | Button shows loading spinner, calls `SyncService.syncPendingLogs()`, updates `pendingCount` in AppState, shows toast with result |
| Force Sync disabled state | Button disabled + grayed out while sync in progress; re-enabled after completion |
| Force Sync when offline | Shows "Tidak ada koneksi internet" toast, does not attempt sync |
| Force Sync when 0 pending | Shows "Tidak ada data pending" toast |
| Back navigation | Standard AppBar back arrow → returns to kiosk idle screen |
| Pending count refresh | Timer every 30 seconds re-reads `SqliteService.countPendingLogs()` and updates display |
| Battery level | Read from `Battery()` on screen init, no periodic refresh (static snapshot) |
| Connectivity status | Listen to `Connectivity().onConnectivityChanged` stream, update in real-time |
