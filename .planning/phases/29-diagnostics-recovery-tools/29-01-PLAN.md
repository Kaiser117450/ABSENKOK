**State variables:**
- `_isSyncing` (bool, default false) — loading state for Force Sync button
- `_pendingCount` (int) — local count from SqliteService, refreshed every 30s
- `_failedCount` (int) — count of logs with sync_status='failed'
- `_batteryLevel` (int?) — from battery_plus
- `_isCharging` (bool?) — from battery_plus
- `_isOnline` (bool) — from connectivity_plus
- `_appVersion` (String) — from package_info_plus
- `_lastSyncResult` (String?) — displays last sync outcome
- `Timer? _refreshTimer` — 30-second periodic count refresh
- `StreamSubscription? _connectivitySub` — connectivity listener

**initState:**
1. Call `_loadDeviceInfo()` — reads battery, version, connectivity
2. Call `_refreshPendingCount()` — reads SQLite count
3. Start `_refreshTimer = Timer.periodic(Duration(seconds: 30), _refreshPendingCount)`
4. Start connectivity listener: `Connectivity().onConnectivityChanged.listen(...)` to update `_isOnline` in real-time

**dispose:**
1. Cancel `_refreshTimer`
2. Cancel `_connectivitySub`

**_loadDeviceInfo():**
- Read `Battery().batteryLevel` → `_batteryLevel`
- Read `Battery().batteryState` → `_isCharging` (charging or full = true)
- Read `PackageInfo.fromPlatform()` → `_appVersion` as `${info.version}+${info.buildNumber}`
- Read connectivity → `_isOnline`

**_refreshPendingCount():**
- `_pendingCount = await SqliteService.countPendingLogs()`
- Also read failed count: query `SELECT COUNT(*) FROM pending_logs WHERE sync_status = 'failed'` via `SqliteService.getDatabase()` then rawQuery. Store in `_failedCount`.
- Update AppState: `ref.read(appProvider.notifier).setPendingCount(_pendingCount)`

**_forceSync():**
1. If `_isSyncing` → return (prevent double-tap)
2. Set `_isSyncing = true` (setState)
3. Check connectivity: if offline, show toast "Tidak ada koneksi internet" with `Icons.wifi_off`, set `_isSyncing = false`, return
4. If `_pendingCount == 0`, show toast "Tidak ada data pending" with `Icons.check_circle`, set `_isSyncing = false`, return
5. Call `final result = await SyncService.syncPendingLogs()`
6. Call `_refreshPendingCount()` to update counts
7. Show result toast:
   - If `result.synced > 0 && result.failed == 0`: success toast "Berhasil — {N} data tersinkron" with `Icons.cloud_done` icon, green accent
   - If `result.synced > 0 && result.failed > 0`: partial toast "Sebagian berhasil — {synced} terkirim, {failed} gagal" with `Icons.warning_amber` icon, amber accent
   - If `result.synced == 0 && result.failed > 0`: failure toast "Sinkronisasi gagal — {N} data tidak terkirim. Coba lagi nanti." with `Icons.error_outline` icon, red accent
   - If `result.synced == 0 && result.failed == 0`: toast "Tidak ada data pending" with `Icons.check_circle`, green
8. Set `_isSyncing = false` (setState)
