Create `lib/services/heartbeat_service.dart` with a static-only class `HeartbeatService`:

**Imports:**
- `dart:async` (Timer)
- `package:flutter/foundation.dart` (debugPrint)
- `package:battery_plus/battery_plus.dart`

- `package:supabase_flutter/supabase_flutter.dart`
- `../models/kiosk_session.dart`
- `sqlite_service.dart`

**Static fields:**
- `static Timer? _timer;`
- `static StreamSubscription<List<ConnectivityResult>>? _connectivitySub;`
- `static KioskSession? _session;`
- `static DateTime? _lastSentAt;`
- `static String? _cachedVersion;`

**Static methods:**

1. `static Future<void> start(KioskSession session) async`
   - Store `_session = session`
   - Call `await _sendHeartbeat()` immediately (first heartbeat on start)
   - Cancel existing `_timer`, create new `Timer.periodic(Duration(minutes: 15), (_) => _sendHeartbeat())`
   - Cancel existing `_connectivitySub`, subscribe to `Connectivity().onConnectivityChanged`
   - On connectivity change: if result is not `ConnectivityResult.none` and `_lastSentAt` is null or >30 seconds ago, call `_sendHeartbeat()`

2. `static void stop()`
   - `_timer?.cancel(); _timer = null;`
   - `_connectivitySub?.cancel(); _connectivitySub = null;`
   - `_session = null;`
   - `_lastSentAt = null;`

3. `static Future<void> _sendHeartbeat() async`
   - Guard: `if (_session == null) return;`
   - Guard: check `supabaseReady` global (import from where it's defined). If not ready, return.
   - Read battery via `_readBattery()`
   - Read app version via `_getAppVersion()`
   - Read pending count via `SqliteService.countPendingLogs()`
   - Build payload map: `{'last_heartbeat_at': DateTime.now().toUtc().toIso8601String(), 'battery_level': battery.level, 'is_charging': battery.isCharging, 'pending_sync_count': pendingCount, 'app_version': appVersion}`
   - Call `_sendWithRetry(payload, _session!.outletId)`
   - On success: `_lastSentAt = DateTime.now()`
   - Wrap entire body in try/catch, debugPrint errors

4. `static Future<({int? level, bool? isCharging})> _readBattery() async`
   - try: `Battery().batteryLevel` and `Battery().batteryState`
   - `isCharging = state == BatteryState.charging || state == BatteryState.full`
   - catch: return `(level: null, isCharging: null)`

5. `static Future<String> _getAppVersion() async`
   - If `_cachedVersion != null`, return it
   - try: `PackageInfo.fromPlatform()` -> `'${info.version}+${info.buildNumber}'`
   - catch: `_cachedVersion = 'unknown'`
   - Return `_cachedVersion!`

6. `static Future<void> _sendWithRetry(Map<String, dynamic> payload, String outletId) async`
   - Loop 3 attempts (0, 1, 2)
   - try: `Supabase.instance.client.from('outlets').update(payload).eq('id', outletId)`
   - On success: return
   - On failure at attempt 2: debugPrint and return
   - Between retries: `await Future.delayed(Duration(seconds: 2 * (attempt + 1)))` (2s, 4s)
