3. Add a helper to safely parse hex to Color (reusing EmployeeBadge._parseHex logic since it's private):
   ```dart
   Color _safeParseHex(String hex, {Color fallback = const Color(0xFF9CA3AF)}) {
     final cleaned = hex.replaceAll('#', '').trim().toUpperCase();
     if (cleaned.length == 6) {
       final v = int.tryParse('FF$cleaned', radix: 16);
       if (v != null) return Color(v);
     }
     return fallback;
   }

   String _colorToHex(Color color) {
     return '#${color.value.toRadixString(16).substring(2).toUpperCase()}';
   }
   ```
