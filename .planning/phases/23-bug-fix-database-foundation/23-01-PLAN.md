Add a new static method `startRegistrationListener` to `NfcService` that is specifically designed for the NFC registration flow (one card, one scan, then stop). This method differs from `startListener` (which is for continuous kiosk scanning) in that it:

1. Accepts the same parameters as `startListener`: `void Function(String uid) onTag` and `void Function(Object err)? onError`
2. Returns `Future<void> Function()` (the cancel callback) -- same as `startListener`
3. Uses an internal `bool _registered = false` lock that is set to `true` on the FIRST successful UID extraction
4. After setting `_registered = true`, immediately calls `NfcManager.instance.stopSession()` BEFORE calling `onTag(uid)` -- this ensures the session is closed before the UI processes the result
5. Any subsequent `onDiscovered` callbacks while `_registered == true` are silently ignored (return early)
6. The cancel callback sets `active = false` and calls `NfcManager.instance.stopSession()` wrapped in try-catch

The method body:

```dart
static Future<void> Function() startRegistrationListener(
  void Function(String uid) onTag,
  void Function(Object err)? onError,
) {
  bool active = true;
  bool registered = false;

  NfcManager.instance.startSession(
    onDiscovered: (NfcTag tag) async {
      if (!active || registered) return;
      registered = true;
      try {
        final uid = extractUid(tag);
        if (uid != null && uid.isNotEmpty) {
          // Stop session BEFORE notifying UI
          try { await NfcManager.instance.stopSession(); } catch (_) {}
          if (active) onTag(uid);
        } else {
          registered = false; // allow retry for unsupported card
          throw Exception('Tipe kartu NFC tidak didukung');
        }
      } catch (e) {
        if (active && !registered) {
          onError?.call(e);
        }
      }
    },
    onError: (error) async {
      if (active) onError?.call(error);
    },
  ).catchError((Object e) {
    if (active) onError?.call(e);
  });

  return () async {
    active = false;
    try { await NfcManager.instance.stopSession(); } catch (_) {}
  };
}
```

Do NOT modify the existing `startListener` method -- it is used by `kiosk_idle_screen.dart` for continuous scanning and works correctly there.

```dart
void _startNfc() {
  if (_isProcessing) return; // prevent starting while already processing
  _isProcessing = true;
  setState(() => _state = _NfcDialogState.scanning);
  _nfcCleanup = NfcService.startRegistrationListener(
    (uid) {
      _isProcessing = false;
      if (!mounted) return;
      if (_state != _NfcDialogState.scanning) return;
      setState(() {
        _scannedUid = uid;
        _state = _NfcDialogState.waiting;
      });
    },
    (err) {
      _isProcessing = false;
      if (!mounted) return;
      setState(() {
        _errorMsg = 'Gagal membaca kartu. Coba lagi.';
        _state = _NfcDialogState.error;
      });
    },
  );
}
```

- Resets `_isProcessing = false` in both success and error callbacks
- Removes `_stopNfc()` call from the success callback (session already stopped by startRegistrationListener)
