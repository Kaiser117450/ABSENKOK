## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding between label+icon |
| sm | 8px | Compact element spacing, chip/badge internal padding |
| md | 16px | Default element spacing, input field horizontal padding, card horizontal margin |
| lg | 24px | Section padding, button horizontal padding |
| xl | 32px | Layout gaps between form sections |
| 2xl | 48px | Major section breaks (e.g., between form and action buttons) |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Touch targets: 48px minimum height for all tappable elements (Material 3 standard)
- Input field vertical padding: 14px (existing `inputDecorationTheme.contentPadding`)
- Button vertical padding: 16px (existing `elevatedButtonTheme`)

**Source:** Existing theme — `cardTheme.margin`, `contentPadding`, button `padding`.

### Interaction Patterns

| Interaction | Behavior |
|-------------|----------|
| Form validation | Real-time validation on blur (name: required min 2 chars, email: valid format, outlet: required selection) |
| Submit button state | Disabled (grayed out) until all fields valid; shows loading spinner on press |
| Password visibility | Hidden by default (dots), toggleable via eye icon — consistent with login screen |
| WhatsApp launch | Opens WhatsApp with pre-filled message via `url_launcher`; if unavailable, falls back to `share_plus` with SnackBar notification |
| PDF generation | Shows brief loading overlay, then triggers native share/print dialog via `printing` package |
| Copy credentials | Copies formatted text to clipboard, shows SnackBar "Kredensial disalin" |
| Create another | Resets form to State 1, clears all fields |
| Back navigation | Standard AppBar back arrow; if in success state, navigates back without confirmation (no data loss risk) |

### Animation & Transitions
