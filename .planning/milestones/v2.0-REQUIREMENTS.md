# Requirements Archive: Absensi Enakko v2.0

**Defined:** 2026-03-11
**Shipped:** 2026-03-12
**Core Value:** Reliable, 24/7 unattended NFC attendance with accurate cross-day shift handling and real-time admin visibility.

## v2.0 Requirements — All Complete

### Employee Archive

- [x] **ARCH-01**: Admin can archive (soft-delete) a karyawan from the active employee list
- [x] **ARCH-02**: Archived karyawan is excluded from NFC scan lookup (cannot clock in)
- [x] **ARCH-03**: Archived karyawan is excluded from schedule assignment and shift selector
- [x] **ARCH-04**: Archive confirmation dialog shows impact summary (jumlah jadwal mendatang yang terdampak)
- [x] **ARCH-05**: Admin can restore (un-archive) a previously archived karyawan
- [x] **ARCH-06**: Admin can view Riwayat Karyawan page showing archived employees with full attendance history

### Batch CSV Import

- [x] **CSV-01**: Admin can upload a CSV file to batch-add multiple karyawan at once
- [x] **CSV-02**: CSV format supports columns: nama, jabatan, gerai (nama outlet), photo_url (link)
- [x] **CSV-03**: System auto-resolves outlet name to outlet UUID (case-insensitive match)
- [x] **CSV-04**: System shows preview screen with parsed rows before committing to database
- [x] **CSV-05**: System detects and reports duplicate karyawan (by name + outlet combination)
- [x] **CSV-06**: System shows per-row validation errors (missing fields, unknown outlet, duplicates)

### Kepala Gerai Setup

- [x] **ADMIN-01**: SQL script template available for Supabase SQL editor to promote any Gmail to Kepala Gerai role for a specific outlet

### Live Activity Pill

- [x] **LIVE-01**: Persistent Dynamic Island-style overlay pill visible outside the app when kiosk is running
- [x] **LIVE-02**: Overlay pill shows real-time break status (nama karyawan yang sedang istirahat)
- [x] **LIVE-03**: Overlay pill shows fun facts / rotating idle messages when no one is on break
- [x] **LIVE-04**: Overlay pill updates automatically without user interaction

## Out of Scope (documented at milestone start)

| Feature | Reason |
|---------|--------|
| Hard delete karyawan | Destroys attendance history, FK violations |
| CSV with NFC UID column | NFC UIDs read from physical cards only |
| Supabase Admin API for Kepala Gerai | Requires service_role key client-side |
| Supabase Realtime in overlay isolate | Overlay runs in separate Dart isolate |
| Android 16 ProgressStyle | Requires API 36+, current minSdk=24 |
| Complex animated overlay widgets | Memory/battery/ANR risk on kiosk tablets |
| Break notification push to admin phone | Requires FCM infrastructure |
| Inline CSV error correction | Admin can fix CSV and re-upload |
