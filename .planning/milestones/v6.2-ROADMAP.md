# Milestone v6.2: Dashboard & Report Foundation

**Status:** ✅ SHIPPED 2026-03-23
**Phases:** 40-41
**Total Plans:** 0 formal plan files recorded

## Overview

Stabilize the admin operational baseline before new feature work by restoring the preferred dashboard flow, keeping chain-wide network visibility available on its own screen, correcting admin branding, and hardening large-volume Rekap Harian PDF exports.

## Phases

### Phase 40: Admin Dashboard Restoration & Brand Refresh

**Goal:** Make the classic operational dashboard the default admin landing again, while preserving a dedicated path to the chain-wide network control center and updating the dashboard brand asset.
**Depends on:** None
**Plans:** No formal PLAN.md / SUMMARY.md files preserved

Execution highlights:

- Restored `/admin/dashboard` to the classic admin dashboard for full-admin users
- Added a dedicated full-admin route and CTA for ringkasan jaringan / status per gerai
- Preserved kepala gerai outlet-scoped visibility by keeping chain-wide network data on a separate full-admin screen
- Replaced the utensil-only admin branding with the intended Enakko dashboard logo from `src/assets/images/logogoenakko.png`

**Details:**
- Requirements: `DASH-01`, `DASH-02`, `DASH-03`, `BRAND-01`
- Routing now keeps the previous operational dashboard as the default admin landing surface
- Chain-wide network visibility remains available without taking over the main dashboard
- Final shipped logo asset path differs from the original milestone draft and was corrected during closeout

### Phase 41: PDF Report Reliability & Count Metrics

**Goal:** Keep Rekap Harian PDF summaries reliable on large exports and replace percentage-based attendance summaries with concrete operational counts.
**Depends on:** Phase 40
**Plans:** No formal PLAN.md / SUMMARY.md files preserved

Execution highlights:

- Reworked PDF summary generation to use a paginated `MultiPage` landscape layout
- Kept per-employee summary content visible even when the export contains hundreds of attendance rows
- Replaced percentage summaries with concrete counts for masuk, tidak hadir, and belum pulang
- Updated per-karyawan summary rows to show count metrics while preserving useful time context

**Details:**
- Requirements: `PDF-01`, `PDF-02`, `PDF-03`
- Export stats now reflect operational counts instead of attendance percentages
- Summary content survives large datasets that previously caused ringkasan sections to disappear
