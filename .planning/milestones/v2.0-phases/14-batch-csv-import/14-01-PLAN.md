**Service implementation** (GREEN phase) in `lib/services/csv_import_service.dart`:

```dart
import 'dart:convert';
import 'dart:typed_data';
import 'package:csv/csv.dart';
import '../models/csv_import_result.dart';
```

Methods:
1. **`static List<CsvRow> parseBytes(Uint8List bytes)`** — decode UTF-8, strip BOM, parse via `CsvToListConverter`, validate header row matches expected columns (`nama`, `jabatan`, `gerai`, `foto_url`), map data rows to `CsvRow`, filter empty trailing rows. Throw `FormatException` on wrong headers or no data.

2. **`static List<CsvRowValidation> validate({...})`** — iterate rows, check: nama required + min 3 chars, gerai required, outlet resolution (case-insensitive via outletNameToId map), foto_url format if non-empty (must start with http:// or https://), duplicate detection within CSV (track `Set<String>` of "lowerName|outletId"), duplicate detection against existingEmployeeKeys. Return `CsvRowValidation` per row.

3. **`static List<Map<String, dynamic>> buildInsertPayloads(List<CsvRowValidation> validRows)`** — map validated rows to Supabase insert payloads. Every payload MUST have these exact keys: `name`, `position`, `home_outlet_id`, `photo_url`, `is_active`. Use `null` for empty optional fields, never omit a key (Pitfall 5 from research).

4. **`static String generateTemplateCsv()`** — return CSV string with header `nama,jabatan,gerai,foto_url` + 2 sample rows (e.g., "Ahmad Fauzi,Kasir,Enakko Sudirman," and "Budi Santoso,Koki,Enakko Margonda,").

5. **`static Future<CsvImportResult> insertAll(List<Map<String, dynamic>> payloads, Map<String, String> outletIdToName) async`** — call `SupabaseClientFactory.admin.from('employees').insert(payloads)`, build `CsvImportResult` with employeesByOutlet grouping. Wrap in try/catch for `PostgrestException` code `23505` (race condition duplicate — rethrow with user-friendly message).

**Key implementation details:**
- Use `const CsvToListConverter(shouldParseNumbers: false)` to keep all values as strings
- BOM strip: `if (content.startsWith('\uFEFF')) content = content.substring(1);`
- Empty row filter: skip rows where `row.every((cell) => cell.toString().trim().isEmpty)`
- Header validation: first row must be exactly `['nama', 'jabatan', 'gerai', 'foto_url']` (case-insensitive comparison on headers too)
