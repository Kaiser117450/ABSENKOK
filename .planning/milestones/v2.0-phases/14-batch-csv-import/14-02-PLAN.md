**Imports needed:**

**State machine:**
```dart
enum ImportStep { upload, preview, confirm, result }
```

**State variables:**
- `ImportStep _currentStep = ImportStep.upload`
- `List<CsvRow> _parsedRows = []`
- `List<CsvRowValidation> _validations = []`
- `CsvImportResult? _importResult`
- `bool _isLoading = false`
- `bool _showErrorPanel = true`
- Pre-fetched outlet data: `Map<String, String> _outletNameToId`, `Map<String, String> _outletNameDisplay`, `Map<String, String> _outletIdToName`
- Pre-fetched employee keys: `Set<String> _existingEmployeeKeys`

**initState:** Fetch outlets and existing employees from Supabase to build lookup maps:
```dart
// Fetch outlets
final outData = await SupabaseClientFactory.admin
    .from('outlets').select('*').eq('is_active', true).order('name');
final outlets = outData.map((o) => Outlet.fromJson(o)).toList();
// Build maps: lowerName→id, lowerName→displayName, id→displayName

// Fetch existing employees for duplicate check
final empData = await SupabaseClientFactory.admin
    .from('employees').select('name, home_outlet_id').eq('is_active', true);
// Build Set<String> of "lowerName|outletId"
```

**Scaffold structure:**
- AppBar with title "Import Karyawan CSV" and back button
- Step indicator row (custom, NOT Material Stepper — per research recommendation): 4 circles with labels (Upload, Preview, Konfirmasi, Hasil), active step highlighted in AppColors.accent, completed steps in AppColors.success
- Expanded body: switch on `_currentStep`

**Step 1 — Upload (`_buildUploadStep`):**
- Centered column with upload icon (Icons.upload_file, large, muted color)
- Text: "Pilih file CSV untuk import karyawan"
- Text: "Format: nama, jabatan, gerai, foto_url"
- Two buttons:
  - "Pilih File CSV" (primary, AppColors.accent) — calls `_pickFile()`
  - "Download Template" (outlined, secondary) — calls `_downloadTemplate()`
- `_pickFile()`: Use `FilePicker.platform.pickFiles(type: FileType.custom, allowedExtensions: ['csv'])`. Null-check result (user may cancel). Read `result.files.single.bytes` (Uint8List). Call `CsvImportService.parseBytes(bytes)` in try/catch. On success → run `CsvImportService.validate(...)` → set state → go to preview step. On FormatException → show `AppToast.error` with the exception message.
- `_downloadTemplate()`: Get template via `CsvImportService.generateTemplateCsv()`, write to temp file, share via `Share.shareXFiles` (same pattern as admin_reports_screen.dart).

**Step 2 — Preview (`_buildPreviewStep`):**
- Summary row at top: "X baris ditemukan • Y valid • Z error" with colored counts
- `SingleChildScrollView` containing a `DataTable` with columns:
  - No (row number)
  - Nama
  - Jabatan
  - Gerai (show resolvedOutletName if valid, original gerai value if error)
  - Status (✅ Icon if isValid, ❌ Icon if not)
- Each DataRow maps from `_validations` list
- Below table: expandable error summary panel (toggled by `_showErrorPanel`):
  - Header: "Detail Error (Z baris)" with expand/collapse icon
  - List of error rows: "Baris X: error1, error2, ..."
  - Only shown if there are errors
- Bottom action bar:
  - If ALL valid: "Lanjutkan Import" button (AppColors.accent) → go to confirm step
  - If ANY errors: "Upload Ulang" button (primary) → reset to upload step. Text: "Perbaiki CSV dan upload ulang"

**Step 3 — Confirm (`_buildConfirmStep`):**
- Summary card: "Anda akan mengimpor X karyawan ke Y outlet"
- List preview: group valid rows by outlet, show outlet name as header + employee names
- Two buttons:
  - "Konfirmasi Import" (AppColors.accent, prominent) — calls `_executeImport()`
  - "Batal" (text button) → go back to preview
- `_executeImport()`: Set `_isLoading = true`, show CircularProgressIndicator. Call `CsvImportService.buildInsertPayloads(validRows)` then `CsvImportService.insertAll(payloads, _outletIdToName)`. On success → set `_importResult` → go to result step → `AppToast.success`. On PostgrestException → `AppToast.error` with user-friendly message → stay on confirm step. Always set `_isLoading = false`.

**Step 4 — Result (`_buildResultStep`):**
- Success icon (Icons.check_circle, large, AppColors.success)
- Text: "X karyawan berhasil diimpor!"
- Grouped list from `_importResult!.employeesByOutlet`: outlet name as section header, employee names as items
- "Kembali ke Karyawan" button → `context.pop()` or `context.go('/admin/employees')`

**Styling rules:**
- Follow existing AppColors palette (primary red, accent amber, success green)
- Use existing AppCard pattern for cards where appropriate
- DataTable with alternating row colors (surface/white)
- Consistent padding: 16px horizontal, 12px vertical for sections
- Error text in AppColors.danger, success in AppColors.success
- Loading state: `_isLoading` shows CircularProgressIndicator overlay on confirm button
