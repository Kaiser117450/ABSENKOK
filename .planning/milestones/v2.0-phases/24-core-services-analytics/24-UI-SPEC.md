## Component Inventory

Phase 24 introduces these UI elements (all embedded in existing `AdminDashboardScreen`):

### 1. AttendanceRateCard

A single Material Card inserted at the top of the admin dashboard scroll body, above the existing today-stats row.

**Layout:**
- Card with `AppColors.surface` background, 12px border radius, 1px `AppColors.border` stroke (matching existing `CardTheme`)
- 16px internal padding on all sides
- Left accent stripe: 4px wide vertical bar, color = success green if rate >= 80%, danger red if < 80%

**Content structure (top to bottom):**
1. **Header row:** "Tingkat Kehadiran" label (12px semibold, `textSecondary`) + period toggle chips (Hari / Minggu / Bulan)
2. **Rate display:** Large percentage "87.5%" (28px extra-bold, color based on threshold) + concrete count "Hadir 14/16 hari" (14px regular, `textSecondary`)
3. **Comparison indicator:** Small arrow icon + delta text "vs minggu lalu" (12px, `textMuted`) — only when weekly or monthly period is selected

**Period toggle:** 3 `ChoiceChip` widgets using existing `chipTheme`. Default selection: "Minggu" (weekly).

### 2. OvertimeAlertRow

A horizontal scrollable row of compact alert chips below the attendance rate card, only visible when overtime flags exist.

**Layout:**
- Horizontal `ListView` with 8px gaps between chips
- Each chip: `warningLight` background, 8px vertical / 12px horizontal padding, 20px border radius
- Icon: `Iconsax.timer_1` at 16px in `AppColors.warning`
- Text: employee name + "+Xj" (e.g., "Budi +2j") in 12px semibold, `AppColors.textPrimary`

**Empty state:** Row is completely hidden (not rendered) when no overtime flags exist.

### 3. Notification Copy (non-visual, notification channel content)

Missing clock-out and late pattern notifications use `flutter_local_notifications` — no in-app widget, only notification tray content. See Copywriting Contract below.

## Interaction Contracts

### AttendanceRateCard
- **Tap on card body:** Show snackbar "Dashboard lengkap segera hadir" (placeholder until Phase 25 chart screen exists)
- **Tap period chip:** Switch between daily/weekly/monthly. Triggers RPC call to `get_attendance_rates` with recalculated date range. Show `CircularProgressIndicator` (16px, `AppColors.primary`) inline while loading.
- **Pull-to-refresh:** Existing dashboard refresh handler also refreshes rate card data.
- **Loading state:** Shimmer placeholder (single rectangle 100% width, 120px height, 12px border radius, `AppColors.surfaceVariant` color) while first RPC call completes.

### OvertimeAlertRow
- **Tap on chip:** No action in Phase 24 (future: navigate to employee detail). Chip has no ripple/splash.
- **Scroll:** Horizontal scroll with `ClampingScrollPhysics`. No scroll indicators.

### Notifications (background)
- **Missing clock-out:** Fires every 30 minutes via timer in foreground service. Channel: `absensi_enakko_missing_clockout`, importance: DEFAULT. Groups per outlet. Tapping notification opens app to dashboard.
- **Late pattern:** Fires immediately after NFC masuk scan when late detected. Channel: `absensi_enakko_late_pattern`, importance: DEFAULT. Tapping notification opens app to dashboard.
