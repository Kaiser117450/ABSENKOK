    **1. Create `sql/phase24_rpc_overtime_missing.sql`:**

    Function `get_overtime_flags(p_outlet_id UUID, p_date DATE, p_threshold_hours NUMERIC DEFAULT 8)`:
    - SECURITY DEFINER, SET search_path = public
    - Auth check: role must be 'admin' or 'kepala_gerai'; kepala_gerai scoped to managed_outlet_id
    - Query: Find employees in outlet (via employees.home_outlet_id) who have BOTH masuk AND pulang on p_date
    - Calculate hours_worked = EXTRACT(EPOCH FROM (pulang.scanned_at - masuk.scanned_at)) / 3600
    - Filter where hours_worked > p_threshold_hours
    - Return JSON array: [{employee_id, employee_name, hours_worked, overtime_hours (hours_worked - p_threshold_hours)}]
    - GRANT EXECUTE to authenticated

    Function `get_missing_clockouts(p_outlet_id UUID, p_threshold_hours NUMERIC DEFAULT 10)`:
    - SECURITY DEFINER, SET search_path = public
    - Same auth check pattern
    - Query: Find employees with masuk today (type='masuk', scanned_at::date = CURRENT_DATE, scan_outlet_id = p_outlet_id)
      but NO subsequent pulang (NOT EXISTS subquery for type='pulang' with scanned_at > masuk.scanned_at)
      AND masuk was more than p_threshold_hours ago (scanned_at < NOW() - INTERVAL '1 hour' * p_threshold_hours)
    - Return JSON array: [{employee_id, employee_name, masuk_time}]
    - GRANT EXECUTE to authenticated

    **2. Create `lib/services/analytics_service.dart`:**

    ```dart
    class AnalyticsService {
      AnalyticsService._();
      static final instance = AnalyticsService._();

      Future<AttendanceRateData?> getAttendanceRates({
        required String outletId,
        required DateTime start,
        required DateTime end,
      }) async {
        if (!supabaseReady) return null;
        try {
          final result = await SupabaseClientFactory.admin.rpc('get_attendance_rates', params: {
            'p_outlet_id': outletId,
            'p_start': start.toIso8601String(),
            'p_end': end.toIso8601String(),
          });
          return AttendanceRateData.fromJson(result as Map<String, dynamic>);
        } catch (e) {
          debugPrint('[AnalyticsService] getAttendanceRates failed: $e');
          return null;
        }
      }

      Future<List<OvertimeFlag>> getOvertimeFlags({
        required String outletId,
        DateTime? date,
        double thresholdHours = 8,
      }) async {
        if (!supabaseReady) return [];
        try {
          final result = await SupabaseClientFactory.admin.rpc('get_overtime_flags', params: {
            'p_outlet_id': outletId,
            'p_date': (date ?? DateTime.now()).toIso8601String().substring(0, 10),
            'p_threshold_hours': thresholdHours,
          });
          return (result as List).map((e) => OvertimeFlag.fromJson(e as Map<String, dynamic>)).toList();
        } catch (e) {
          debugPrint('[AnalyticsService] getOvertimeFlags failed: $e');
          return [];
        }
      }

      Future<List<MissingClockout>> getMissingClockouts({
        required String outletId,
        double thresholdHours = 10,
      }) async {
        if (!supabaseReady) return [];
        try {
          final result = await SupabaseClientFactory.admin.rpc('get_missing_clockouts', params: {
            'p_outlet_id': outletId,
            'p_threshold_hours': thresholdHours,
          });
          return (result as List).map((e) => MissingClockout.fromJson(e as Map<String, dynamic>)).toList();
        } catch (e) {
          debugPrint('[AnalyticsService] getMissingClockouts failed: $e');
          return [];
        }
      }
    }
    ```

    Data classes in same file:
    - `AttendanceRateData`: `totalEmployees` (int), `daysInRange` (int), `totalPresent` (int), `rate` (double) + `fromJson`
    - `OvertimeFlag`: `employeeId` (String), `employeeName` (String), `hoursWorked` (double), `overtimeHours` (double) + `fromJson`
    - `MissingClockout`: `employeeId` (String), `employeeName` (String), `masukTime` (DateTime) + `fromJson`
