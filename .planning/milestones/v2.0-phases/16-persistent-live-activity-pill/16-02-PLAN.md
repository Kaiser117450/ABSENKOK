       ```dart
       static Future<void> _rotateNotification() async {
         final session = _session;
         if (session == null) return;

         final now = DateTime.now();
         final timeStr = _formatClock(now);

         // Get next display content from live content provider
         final displayText = _liveContent.nextDisplayText();
         final hasBreak = _liveContent.hasActiveBreaks;

         // Accent: amber when someone is on break, green otherwise
         final accentHex = hasBreak ? '#F59E0B' : '#22C55E';
         // attendanceType: 'break' for amber accent resolution, 'masuk' for green
         final attendanceType = hasBreak ? 'break' : 'masuk';

         final idleOverlayState = OverlayPillState(
           mode: OverlayPillMode.idle,
           outlet: session.outletName,
           time: timeStr,
           attendanceType: attendanceType,
           accentHex: accentHex,
           displayLabel: displayText,
           eventUntilEpochMs: 0,
           expanded: true,
         );

         await updateOverlayState(idleOverlayState);

         // Also update notification bar
         await updateLiveNotification(
           outletName: session.outletName,
           body: displayText,
         );

         FlutterForegroundTask.updateService(
           notificationTitle: session.outletName,
           notificationText: displayText,
         );
       }
       ```

    7. **Remove `_showingTime` field** — it's no longer needed since content rotation is now handled by LiveContentProvider.nextDisplayText() instead of the old toggle.

    8. **Update `_buildIdleOverlayState()`** to include displayLabel:
       ```dart
       static OverlayPillState _buildIdleOverlayState({
         String? outletName,

           expanded: true,
         );
       }
       ```

    CRITICAL: Event mode priority (Research Pitfall 2).
    The overlay's `_applyIncomingState` does NOT block idle payloads when event is active — idle pushes WILL overwrite event state.
    Solution: Track event expiry in KioskBackgroundService and skip rotation while event is active.

    Add a static field `static int _eventUntilEpochMs = 0;` that is set when event mode is pushed (by kiosk_scan_screen), and check in _rotateNotification:
    ```dart
    // At top of _rotateNotification:
    if (_eventUntilEpochMs > 0 && DateTime.now().millisecondsSinceEpoch < _eventUntilEpochMs) {
      return; // Event still active, don't overwrite
    }
    _eventUntilEpochMs = 0; // Expired, clear
    ```

    And add a public method to set it:
    ```dart
    /// Call when pushing event mode overlay to prevent idle rotation overwriting it.
    static void markEventActive(int eventUntilEpochMs) {
      _eventUntilEpochMs = eventUntilEpochMs;
    }
    ```

    Then in `kiosk_scan_screen.dart` (wherever it calls `updateOverlayState` with event), also call `KioskBackgroundService.markEventActive(eventUntilEpochMs)`. Search for `OverlayPillMode.event` usage in kiosk_scan_screen.dart to find the exact location.
