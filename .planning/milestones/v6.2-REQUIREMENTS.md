# Milestone v6.2 Requirements

**Coverage:** `7/7` implemented in milestone traceability
**Audit Status:** no dedicated milestone audit file; archived from shipped code and release evidence on 2026-03-23

## 1. Admin Dashboard Flow
- [x] **DASH-01**: Full admin lands on the classic admin dashboard at `/admin/dashboard` instead of the chain-wide network control center.
- [x] **DASH-02**: The admin dashboard provides a dedicated action to open the separate ringkasan jaringan and status per gerai screen without removing the classic operational dashboard content.
- [x] **DASH-03**: Kepala gerai remains limited to outlet-scoped admin visibility and does not gain access to full-admin-only chain-wide network data.

## 2. Brand Refresh
- [x] **BRAND-01**: The admin dashboard hero/header renders the intended official Enakko logo asset (`src/assets/images/logogoenakko.png`) instead of the utensil-only mark.

## 3. Attendance PDF Reliability
- [x] **PDF-01**: Rekap Harian PDF keeps the per-employee summary visible even when the selected export range produces hundreds of attendance rows.
- [x] **PDF-02**: Rekap Harian PDF summary cards show concrete counts for hadir, tidak absen, and belum absen pulang within the selected date range instead of attendance percentage.
- [x] **PDF-03**: Rekap Harian PDF per-employee summary rows show count-based values for hadir, tidak absen, and belum absen pulang while preserving useful supporting time context.
