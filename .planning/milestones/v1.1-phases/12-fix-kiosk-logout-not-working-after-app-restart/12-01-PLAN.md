# Plan 01: Make Kiosk Logout Resilient After App Restart

## Goal
Fix the bug where the kiosk logout button ("Reset Perangkat") does not work after the app is closed and reopened. Logout works on first login but fails after cold restart with a persisted session.

## Root Cause
The `_confirmLogoutGerai()` handler in `kiosk_idle_screen.dart` calls `KioskBackgroundService.stop()` **without try-catch or timeout**. After an app restart, the background service is fully initialized (foreground task, overlay, live notification), and `stop()` calls `FlutterForegroundTask.stopService()`, `_notifPlugin.cancel()`, `dismissLiveNotification()`, and `hideOverlayPill()` sequentially with **no individual error isolation**. If ANY of these throws or hangs (especially `FlutterForegroundTask.stopService()` after a cold restart where the service may be in an inconsistent state), the entire async chain aborts — `clearKioskSession()` never executes, the kiosk state is never cleared, and GoRouter never redirects to `/setup`.

Secondary contributing factor: the explicit `context.go('/setup')` at line 561 relies on `mounted` being true, but GoRouter's redirect (triggered by `clearKioskSession()`) may have already disposed the widget, making this redundant safety net unreliable.

## Approach
1. Make `KioskBackgroundService.stop()` fully resilient: wrap each internal step in its own try-catch so one failure cannot block subsequent steps.
2. Add a 5-second timeout to the `stop()` call in the logout handler as a belt-and-suspenders guard.
3. Ensure `clearKioskSession()` ALWAYS runs regardless of whether `stop()` succeeds, fails, or times out.
4. Add debug logging to every step of the logout flow for future diagnosis.
5. Verify `clearKioskSession()` actually removes the SharedPreferences key by adding a read-back verification.

<title>Make KioskBackgroundService.stop() individually resilient</title>
<description>
Refactor `KioskBackgroundService.stop()` in `lib/services/kiosk_background_service.dart` so that each cleanup step is wrapped in its own try-catch block. This ensures that if `FlutterForegroundTask.stopService()` throws, the notification cancel, live notification dismiss, and overlay hide still execute.

Current code (lines 165-182):
```dart
static Future<void> stop() async {
  _rotateTimer?.cancel();
  _rotateTimer = null;
  _session = null;
  await FlutterForegroundTask.stopService();
  await _notifPlugin.cancel(_kNotifIdPersistent);
  await dismissLiveNotification();
  await hideOverlayPill();
  debugPrint('[BgService] stopped');
}
```

Change to:
```dart
static Future<void> stop() async {
  _rotateTimer?.cancel();
  _rotateTimer = null;
  _session = null;
  try {
    await FlutterForegroundTask.stopService();
  } catch (e) {
    debugPrint('[BgService] stop: stopService error: $e');
  }
  try {
    await _notifPlugin.cancel(_kNotifIdPersistent);
  } catch (e) {
    debugPrint('[BgService] stop: cancel persistent notif error: $e');
  }
  try {
    await dismissLiveNotification();
  } catch (e) {
    debugPrint('[BgService] stop: dismissLiveNotification error: $e');
  }
  try {
    await hideOverlayPill();
  } catch (e) {
    debugPrint('[BgService] stop: hideOverlayPill error: $e');
  }
  debugPrint('[BgService] stopped (all steps attempted)');
}
```

<description>

Change the onPressed from:
```dart
onPressed: () async {
  Navigator.pop(ctx);
  await KioskBackgroundService.stop();
  await ref.read(appProvider.notifier).clearKioskSession();
  await Future.delayed(const Duration(milliseconds: 100));
  if (mounted) context.go('/setup');
},
```

To:
```dart
onPressed: () async {
  Navigator.pop(ctx);
  debugPrint('[Logout] starting logout flow');

  // Step 1: Stop background services (best-effort, never blocks logout)
  try {
    await KioskBackgroundService.stop()
        .timeout(const Duration(seconds: 5));
    debugPrint('[Logout] background service stopped');
  } catch (e) {
    debugPrint('[Logout] stop() failed/timed out: $e');
  }

  // Step 2: ALWAYS clear kiosk session (the critical step)
  try {
    await ref.read(appProvider.notifier).clearKioskSession();
    debugPrint('[Logout] kiosk session cleared');
  } catch (e) {
    debugPrint('[Logout] clearKioskSession error: $e');
  }

  // Step 3: Explicit navigation (belt-and-suspenders with GoRouter redirect)
  if (mounted) {
    debugPrint('[Logout] navigating to /setup');
    context.go('/setup');
  } else {
    debugPrint('[Logout] widget already unmounted (GoRouter redirect handled it)');
  }
},
```

Key change: `clearKioskSession()` runs regardless of whether `stop()` succeeds, and explicit navigation happens immediately after (no artificial 100ms delay).
